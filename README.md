## Liste des projets

| # | Projet | Description | Technologies |
|---|--------|-------------|--------------|
| 1 | **E-commerce Sales Analytics** | Analyse des ventes d'une boutique en ligne pour identifier les produits, clients et tendances clés. | Python, Pandas, Matplotlib, Seaborn |
| 2 | **Superstore Business Intelligence** | Dashboard Power BI pour suivre la performance commerciale, la rentabilité et les segments stratégiques. | Power BI, Power Query, DAX |
| 3 | **Customer Churn Analytics** | Analyse du taux de désabonnement client avec segmentation et modélisation prédictive. | Python, Scikit-learn, Power BI |
| 4 | **Hotel Booking Analytics** | Étude des réservations hôtelières pour réduire les annulations et améliorer la gestion des capacités. | Python, Pandas, Power BI |
| 5 | **NYC Taxi Data Analytics** | Analyse des trajets de taxis new-yorkais pour optimiser l'allocation et comprendre la demande temporelle. | PostgreSQL, SQL, Python, Power BI |




## Compétences démontrées

- **Analyse de données** : exploration, nettoyage, feature engineering
- **Visualisation** : graphiques statistiques, dashboards interactifs
- **SQL** : requêtes complexes, optimisation, modélisation
- **Business Intelligence** : Power BI, DAX, modèles en étoile
- **Machine Learning** : classification, évaluation de modèles
- **Storytelling** : traduction des données en recommandations opérationnelles


## Environnement technique

- **Langages** : Python, SQL
- **Bibliothèques Python** : Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Bases de données** : PostgreSQL
- **BI** : Power BI
- **Outils** : Jupyter Notebook, Power Query, Excel
